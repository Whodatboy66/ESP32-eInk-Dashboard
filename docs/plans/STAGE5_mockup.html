Limits I'm designing around

No internet in setup modeThe phone talks only to the device. Everything (layout, scripts, icons) comes from the device's own memory: system fonts, no downloads.
Small enough for the firmwareThe whole app as one compressed file, about 40-60 KB. The firmware uses 1.47 of 1.92 MB, so there is room.
The device sleepsChanges only arrive while it's awake: in setup mode, or later in an "edit mode" on the home network (stage 5 already plans that, opened by a long touch).
PreviewThe phone draws a quick sketch like the one above while you edit. For the exact picture, the device can draw it itself (the same drawing code that makes the layout images today).
One grid underneathBoxes snap to the 4 × 3 grid of stage 3 (200 × 150 px cells). Widgets keep their minimum sizes; the device checks every layout and falls back to Classic if one is ever broken.
Classic staysToday's screen remains selectable as a structure, unchanged.
